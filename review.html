01 / Framingすれ違いの構造

この分野の文献を通読して最初に気づくのは、論争の多くが「同じ問題について異なる意見を述べていた」のではなく、「異なる問題について同じ語彙を使っていた」ということである。

2018 年から 2026 年にかけて、Transformer の Attention 機構が持つ O(n²) の計算量を巡って、おそらく 200 本を超える改良提案が発表された。そのうち、フロンティアの大規模言語モデルで既定の Attention 機構として採用されたものは、ひとつもない。

これは失敗の物語ではない。むしろ、問題が正しく定義されるまでに長い時間がかかり、定義され直した瞬間に大量の研究が一斉に無効化され、そして別の場所で戦線が再形成された、という問題定義の移動の物語である。本レビューはその移動を追跡する。

すれ違いの核心は単純である。「Attention が重い」という一文が、実際には少なくとも四つの異なる主張を含んでいた。

  1. 浮動小数点演算数が n² に比例する。 系列長を倍にすれば演算が 4 倍になる。
  2. n×n の行列がメモリ上に実体化される。 演算数とは独立に、中間結果の格納と読み書きが発生する。
  3. 自己回帰生成のために過去の状態を保持し続ける必要がある。 KV キャッシュは系列長に比例して増え続ける。
  4. 厳密な softmax Attention でなければ品質が出ない。 近似はどこまで許されるのか。

第一波の研究（2018–2022）はほぼ全てが (1) を攻撃した。ところが 2022 年の FlashAttention は (1) を一切改善せずに (2) だけを解き、それだけで実測速度において大半の「線形 Attention」を上回った。この一件で (1) を前提とした研究群の存在理由が消えた。そして問題は (3) へ移動する。KV キャッシュこそが、推論時代の真のボトルネックだった。

したがって本レビューは、各手法を次の 4 軸で分類して読む。この軸を分けずに「O(n²) を解いた」と述べる限り、議論は噛み合わない。

B. 実体化n×n をメモリに置かずに済むかFlashAttention, Ring Attention素朴な Linformer 実装
C. 状態サイズKV／再帰状態を劣線形にしたかMLA, Mamba, StreamingLLMFlashAttention, GQA（定数倍のみ）

本レビューの主張

効率的 Attention 研究の 8 年間は、A 軸（FLOPs）に賭けた第一波の敗北、B 軸（実体化）を解いた FlashAttention による前提の破壊、そして C 軸（状態サイズ）へ移動した第二波として整理できる。D 軸（厳密性）は、この移動の全期間を通じて「どこまで諦めてよいか」を測る唯一の通貨であり続け、2024 年以降はその通貨の目盛り自体（＝評価ベンチマーク）が信頼を失いつつある。

02 / Formulation問題の定式化

2.1 二つのフェーズ、二つのボトルネック

Transformer の推論は、性質が根本的に異なる二つのフェーズからなる。この区別を落とすと、あらゆるコスト議論が曖昧になる。

Prefill（プロンプト処理）では、長さ n の入力を一括で投入する。Attention は n×n のスコア行列を必要とし、計算量は O(n²d)。行列同士の積が中心で演算強度（FLOPs / byte）が高いため、GPU の Tensor Core を飽和させられる。すなわち compute-bound である。

Decode（自己回帰生成）では、1 トークンずつ処理する。1 ステップあたりの Attention 演算は O(nd) にすぎない。ところが、そのために KV キャッシュ全体を毎ステップ HBM から読み出す必要がある。演算は行列とベクトルの積となり、演算強度が潰れる。すなわち memory-bandwidth-bound である。

2.2 KV キャッシュのサイズ

KV キャッシュの大きさは初等的な式で与えられる。だが、この式の各項がそれぞれ独立した研究プログラムを生んだ、という事実が本レビューの後半を構成する。

KV cache size (bytes) S_kv = 2 × L × H_kv × d_head × n × B × b

各項 2 … K と V の二つ
L … 層数
H_kv … 保存する KV ヘッド数（クエリヘッド数とは別）
d_head … ヘッド次元
n … 系列長
B … バッチサイズ
b … 要素あたりバイト数

具体的な数値を置くと問題の深刻さが見える。LLaMA-2-70B は 1 トークンあたり約 2.5 MB の KV キャッシュを要する。32K トークンの系列 1 本だけで約 80 GB となり、バッチ処理を始める前に H100 一枚の HBM を使い切る。

より示唆的なのは、アーキテクチャ選択だけで生じる差である。FP16 における 1 トークンあたりの KV フットプリントは、LLaMA-3.1-405B（GQA）が約 516 KB、Qwen-2.5-72B（GQA）が約 327 KB、DeepSeek-V3（MLA）が約 70 KB。4.7 倍から 7.4 倍の開きが、Attention ヘッドの設計という一点だけから生じている。

2.3 デコードのローフラインと、KV 削減という稀な軸

1 トークンの生成に必要な HBM 転送量は、おおよそ「モデル重み + KV キャッシュ」である。したがって 1 ステップの所要時間は帯域幅で下から抑えられる。

t_step ≳ (W + S_kv) / BW_HBM

この単純な式から、二つの重要な帰結が出る。

  • KV を減らすことは、そのまま生成レイテンシの短縮になる。 品質を落とさずに KV を半分にできれば、デコードは（重みが支配的でない領域で）ほぼ二倍速くなる。
  • バッチを増やしても KV は償却されない。 モデル重みの読み出しはバッチ内の全リクエストで共有できるが、KV キャッシュはリクエストごとに固有である。ゆえに Attention は、バッチサイズをどれだけ上げても memory-bound のままであり続ける。

この二点目が、KV 削減を特異な位置に置いている。通常、レイテンシとスループットはトレードオフの関係にある。しかし KV キャッシュの削減は、レイテンシを短縮すると同時に、同一メモリでより大きなバッチを積めるようにすることでスループットも上げる。両方を同時に改善しうる、稀な軸なのである。

この経験則の裏付けとして、H100 と B200 は Tensor Core のスループットが近いにもかかわらず、B200 のデコードは約 2.4 倍速い。これは両者のメモリ帯域比（3.35 対 8 TB/s）にほぼ一致する。ボトルネックが演算ではなく帯域であることの、直接的な証拠である。

03 / First Wave第一波：近似の時代 2018–2022

「二次の計算量は高すぎる。ゆえに近似せよ」——この前提のもとに、5 つの系統が並行して展開した。そのいずれも、フロンティアモデルの既定機構にはならなかった。

3.1 固定パターン疎化

この系統の起点は Attention 論文の翌年にある。Generating Wikipedia by Summarizing Long Sequences（Liu ら, 2018.1, arXiv:1801.10198）が導入した T-DMCA は、局所ブロック Attention に加えてK と V をストライド畳み込みで圧縮してから参照する。実効的な参照長そのものを縮める発想であり、ここでの「メモリ圧縮」が指すのは推論時キャッシュではなく文脈である点に注意が要る。

最も直接的な発想は、Attention 行列の大半を単に計算しないことである。Sparse Transformer（Child ら, 2019, arXiv:1904.10509）は、ストライド型と固定型の二つの疎パターンを層をまたいで合成することで、数層かければ全結合と同等の受容野が得られるとした。計算量は O(n√n)。

この系統は Longformer（2020, arXiv:2004.05150）と BigBird（2020, arXiv:2007.14062）で完成をみる。前者は「スライディングウィンドウ + タスク固有のグローバルトークン」、後者はそこにランダム結合を加え、Watts–Strogatz 型のグラフ構造によって疎でありながら万能近似能力とチューリング完全性を持つことを証明した。

理論的正当性と実測速度の乖離

BigBird は Long Range Arena において平均品質で最良だった。にもかかわらず、実測速度は素の Attention とほとんど変わらなかった。ブロック疎とランダム結合の gather パターンが GPU/TPU の行列積ユニットに乗らないためである。「理論上の FLOPs 削減」が「実測の高速化」を意味しないという、この分野を貫く教訓の最初の明確な事例である。

3.2 学習型・クラスタリング型疎化

パターンを手で設計する代わりに、どこを見るかをデータから学ばせる系統である。Reformer（2020, arXiv:2001.04451）は局所性鋭敏ハッシュ（LSH）で内積が大きくなりそうなトークン同士を同じバケットに落とし、O(n log n) を達成した。加えて可逆残差層により層数に依存しないメモリを実現している。Routing Transformer（2020, arXiv:2003.05997）はオンライン k-means でクラスタリングし O(n^1.5·d)、Sinkhorn Transformer（2020, arXiv:2002.11296）は微分可能なソートで系列を並べ替えてから局所窓を当てる。

ここで一点、分類上の注意が必要である。Adaptively Sparse Transformers（2019, arXiv:1909.00015）が導入した α-entmax は、softmax を厳密なゼロを出力しうる関数に置き換えるが、計算量は一切下げない。n² 個のペアを密に計算した後で重みが疎になるだけである。「スパース Attention」という語が、コスト削減と解釈可能性という二つの無関係な目的に使われてきたことの典型例であり、文献読解の際の混同の主要因のひとつである。

3.3 低ランク・カーネル・線形 Attention

本系統は、この分野で最も影響が大きく、かつ最も採用されなかった。

起点は通説より 2 年早い。Efficient Attention（Shen ら, 2018.12, arXiv:1812.01243）は、softmax を Q の行方向と K の列方向へ別々に適用したうえで KᵀV を先に計算する順序替えにより、O(n²d) を O(nd²) へ落とした。カーネル特徴写像による近似ではなく積の順序を替えるだけである点で、のちの Performer とは性質が異なる。ただし検証は物体検出・セグメンテーション・ステレオ深度に限られ、因果デコードも KV キャッシュも視野に入っていない。線形化のアイデア自体は言語モデルの文脈が生まれる前から存在していた、というのが正確な理解である。

Linformer（2020, arXiv:2006.04768）は Attention 行列が近似的に低ランクであることを実証し、キーと値を系列方向に固定長 k へ射影した。O(n) を達成する。しかし時間ステップ方向への射影は未来と過去を混合するため、因果的な自己回帰生成と原理的に相性が悪い。これは実装上の不備ではなく、手法の定義そのものに埋め込まれた性質である。

より本質的な貢献は Linear Transformer（Katharopoulos ら, 2020, arXiv:2006.16236）にある。softmax(QKᵀ)V をカーネル特徴写像 φ で置き換えると φ(Q)(φ(K)ᵀV) となり、行列積の結合律により累積和として計算できる。すなわち因果的線形 Attention は固定サイズ状態を持つ RNN と等価である。この論文の標題「Transformers are RNNs」が示す等価性は、当時の実用的インパクトこそ限定的だったが、2023 年以降の状態空間モデル復興の理論的基盤そのものとなった。本レビューにおける最重要の系譜的結節点である。

3.4 再帰と外部メモリ

系列を分割して状態を持ち越す発想である。Transformer-XL（2019, arXiv:1901.02860）はセグメント単位の再帰と相対位置符号化を導入し、Compressive Transformer（2019, arXiv:1911.05507）は溢れた記憶を破棄する代わりに圧縮して二次記憶へ移す。Memorizing Transformers（2022, arXiv:2203.08913）は非微分可能な外部 kNN 記憶へ 262K トークンを退避させ、∞-former（2021, arXiv:2109.00301）は長期記憶を連続信号（RBF 係数）として表現し、記憶コストをトークン数から完全に切り離した。

この系統は当時ほとんど採用されなかったが、系譜としては最も長く生き延びた。Compressive Transformer の「古い記憶を捨てずに圧縮する」という発想は、そのまま 2023 年以降の KV キャッシュ圧縮（H2O, SnapKV）へ接続する。Memorizing Transformers は RAG と、後述する RetrievalAttention・ShadowKV の CPU 退避＋近傍探索へ接続する。

3.5 なぜ全滅したのか

2022 年までに、この波の総括はほぼ確定した。理由は単一ではなく、少なくとも 6 つが積み重なっている。

  1. 支配的手法が存在しなかった。 Long Range Arena（2021, arXiv:2011.04006）は 10 手法を統一比較し、明確な勝者がいないことを示した。BigBird は品質が最良だが速くない。Performer は 4K 長で約 5.7 倍速いが ListOps で崩れる。タスクごとに勝者が違う。標準化すべき既定値が存在しない以上、単純で一様に「十分よい」素の Attention が残るのは自然な帰結だった。
  2. スケールで差が縮まらなかった。 Scaling Laws vs Model Architectures（2022, arXiv:2207.10551）は、Performer を含むいくつかの効率的アーキテクチャが素の Transformer よりスケール則が悪いことを示した。モデルを大きくすれば近似の傷が埋まる、という期待の正反対である。フロンティア規模の事前学習に賭ける理由が消えた。
  3. 因果デコードとの非互換。 最も強力な手法群（Linformer, BigBird, ETC, Longformer, Nyströmformer）は本質的に双方向・エンコーダ指向だった。生成 LLM の支配的パラダイムである厳密な因果デコードへの適用には、非自明な再設計を要するか、効率の前提そのものが崩れた。
  4. 定数項が大きく、交差点が遠かった。 CAB（2022, arXiv:2210.07661）は「efficiency length」——効率手法が素の Attention の実測速度を上回り始める系列長——を定式化した。多くの手法でそれは数千トークンであり、当時の実タスクの大半はその手前にあった。つまりほとんどの場面で「効率的」手法の方が遅かった。
  5. そもそも長距離文脈が使われていなかった。 Do Long-Range LMs Actually Use Long-Range Context?（2021, arXiv:2109.09115）は、長距離モデルの perplexity 改善の多くが局所統計に由来し、遠方の文脈が実質的に活用されていないことを示した。前提そのものが揺らいだ。
  6. 低ランク近似には数学的な品質天井があった。 Scatterbrain（2021, arXiv:2110.15343）は、疎近似は低エントロピー（スパイキー）な Attention に、低ランク近似は高エントロピーな Attention に適することを定式化し、両者が相補的であることを示した。学習済み言語モデルの Attention は特徴的にスパイキーである。ゆえにカーネル／低ランク系は、構造的にそれをぼかす。2023 年の arXiv:2310.11685 はこれを「低エントロピー性と内積の単調性」という二性質として明示した。エンジニアリングの不足ではなく、数式に埋め込まれた限界だった。

この系統の締めくくりに位置するのが The Devil in Linear Transformer（Qin ら, EMNLP 2022, arXiv:2210.10340）である。線形化がなぜ失敗するのかを二つの故障モードに分解した——(1) カーネルそのものではなく softmax のスケーリング操作に由来する勾配の発散、(2) 系列が長くなるとスコアが薄く広がる Attention の希薄化。前者はスケーリングを正規化へ置き換え、後者は浅い層を局所帯域にマスクすることで対処する。結果が TransNormer である。第 3.5 節で見る「線形系の構造的天井」を、Scatterbrain の情報理論的な説明とは別の角度——最適化の安定性——から診断した点に価値がある。そしてこれが TransNormerLLM を経て、第 7 章の Lightning Attention（MiniMax-01）へ直接つながる。

ただし、この波が無意味だったわけではない。Katharopoulos らの RNN 等価性と RFA のゲート機構は、第二波の中核部品としてそのまま再利用される（第 6 章）。cosFormer の系譜は上記の TransNormer を経て MiniMax の Lightning Attention へ接続した。アイデアは死ななかった。前提だけが死んだ。

04 / The Turn転回：FlashAttention が壊した前提

2022 年、この分野の問いは「どう近似するか」から「そもそも近似は必要か」へ反転した。反転させたのは新しい近似ではなく、厳密なカーネルだった。

4.1 前史：オンライン softmax と O(n²) メモリの不要性

転回の材料は先に揃っていた。Milakov & Gimelshein（2018, arXiv:1805.02867）は softmax を、走査中に最大値と正規化和を更新し続ける 1 パスの漸化式で計算できることを示した。新しい最大値が現れたら、それまでの累積和を再スケールすればよい。この漸化式が、以後のあらゆるタイル化 Attention カーネルの数学的中核となる。

Rabe & Staats（2021, arXiv:2112.05682）の標題は問題を端的に述べている——「Self-attention Does Not Need O(n²) Memory」。分割統治と再計算により、基本 Attention は O(1)、微分込みでも O(log n) のメモリで計算できる。実用的には O(√n) 版が提示され、系列長 16384 においてメモリ超過を推論で 59 倍、微分で 32 倍削減しながら実行時間は数パーセント差に収まった。この実装は FlashAttention 以前に xFormers の memory_efficient_attention としてそのまま提供されている。

4.2 FlashAttention が実際に変えたもの

ここが本レビューで最も重要な概念的区別である。FlashAttention（2022, arXiv:2205.14135）は Attention の FLOPs を一切減らしていない。 n² 個のスコアを全て計算する。厳密である。近似ではない。

素朴な多カーネル実装が追加で行っていたのは、中間行列 S = QKᵀ と softmax(S) をカーネル起動の合間に HBM へ書き出し、読み戻すことだった。これが O(n²) のメモリと、O(n²) の HBM 往復トラフィックを生んでいた。FlashAttention は QKᵀ → softmax → ·V を単一カーネルへ融合し、Q/K/V を SRAM に収まるタイルで処理し、オンライン softmax 漸化式で行ごとの最大値と和だけを保持し、逆伝播では保存の代わりに再計算する。

FlashAttention の帰結

ピークメモリは O(n²) から O(n) へ。HBM トラフィックは O(n²) から Θ(n²d²/M) へ（M は SRAM サイズ）。そして論文はこれが下界に一致することを証明した。すなわち、与えられた SRAM サイズのもとで、厳密な Attention をこれより少ない HBM アクセスで計算するアルゴリズムは存在しない。FlashAttention は単に速いのではなく、IO 最適である。

なぜこれで速くなるのか。現代の GPU は演算スループット（数百 TFLOPs）がメモリ帯域（1.5–3 TB/s）を大きく上回る。素朴実装における Attention の演算強度は、GPU が compute-bound を保つのに必要な比を大きく下回っていた。つまりAttention は実は memory-bound だった。ゆえに IO を削れば、FLOPs が変わらなくてもその分だけ実時間が縮む。

4.3 デコード側への拡張と、その先

Prefill を解いた後、同じ思想が decode へ向かう。Flash-Decoding（2023）は、クエリが 1 トークンしかない decode では batch×heads の並列度だけでは GPU が飽和しないことに着目し、KV キャッシュを系列方向へ分割して部分 Attention を並列計算し、log-sum-exp で統合する。長文脈で最大 8 倍。FlashDecoding++（2023, arXiv:2311.01282）は部分 softmax の同期コスト（約 20%）を統一最大値の採用で除去した。

並行して、厳密性を保ったまま系列を複数デバイスへ分散する系統が現れる。Ring Attention（2023, arXiv:2310.01889）はデバイスをリング状に並べ、K/V ブロックを巡回させながら、次ブロックの通信を現ブロックの計算に重ねる。近似は一切ない。Striped Attention（2023, arXiv:2311.09431）は因果マスク下での負荷不均衡（連続分割だと三角形の空きブロックを持つデバイスが出る）をストライプ分割で解消し、最大 1.65 倍を得た。DeepSpeed-Ulysses（2023, arXiv:2309.14509）は all-to-all でヘッド並列へ組み替える別解を採り、USP（arXiv:2405.07719）が両者を統一した。

そして 2024 年以降、この系統はカーネルを書く仕事そのものの抽象化へ向かう。FlexAttention（arXiv:2412.05496）は score_mod / mask_mod というユーザ関数を受け取り、torch.compile がブロック疎 Triton カーネルへ落とす。ALiBi、スライディングウィンドウ、文書マスク、prefix-LM——かつて一つずつ手で CUDA を書く必要があった「Flash + X」の長い裾が、まとめて吸収された。FlashInfer（arXiv:2501.01005）は同様の役割をライブラリとして担い、SGLang・vLLM・MLC の共通バックエンドとなっている。

前提が消えるということ

2019–2021 年の効率的 Transformer 研究は、実時間コストが漸近計算量に追随するという暗黙の前提の上に立っていた。FlashAttention はこの前提が、当時実用されていた系列長において誤りであることを示した。厳密な O(n²) FLOPs の Attention が、IO 最適に実装されれば、近似的な O(n) 手法より実測で速い。近似側の理論的節約は、依然として memory-bound な複数カーネル起動に食われ、その上で品質の代償まで払っていた。

以後、新しい Attention 効率化提案は「素朴な Attention」ではなく「厳密かつ既に IO 最適に近いカーネル」を上回らねばならなくなった。これが、既定機構としての近似 Attention 研究プログラムを静かに終わらせた。

05 / Relocation戦場の移動：KV キャッシュ

学習時の FLOPs が解かれたわけではない。だが、産業の重心が学習から推論へ移り、ボトルネックが演算から帯域へ移った結果、コスト式の主役が交代した。

第 2 章の式を再掲する。S_kv = 2 · L · H_kv · d_head · n · B · b。この式が示唆に富むのは、各項がそれぞれ独立した研究プログラムを生んだことにある。文献の見取り図として、これ以上に効率的な整理はない。

5.1 アーキテクチャ側：MQA から MLA へ

MQA（Shazeer, 2019, arXiv:1911.02150）は全クエリヘッドで単一の KV ヘッドを共有し、キャッシュをヘッド数分の 1 にした。しかし共有が過激すぎて品質が落ちる。GQA（2023, arXiv:2305.13245）はクエリヘッドをグループ化して各グループが 1 つの KV ヘッドを共有する中間解を採り、さらに既存 MHA チェックポイントの KV ヘッドを平均プーリングして少量の追加学習（元の事前学習計算の 5%）で復元できることを示した。この移行の容易さが決定的で、GQA は LLaMA-2/3、Mistral をはじめ事実上の標準となった。

MLA（DeepSeek-V2, 2024, arXiv:2405.04434）は発想を変える。ヘッド間で共有するのではなく、K と V を結合して低ランクの潜在ベクトルへ圧縮し、キャッシュするのはその潜在表現だけとする。ヘッドごとの K/V は必要時に再構成する。RoPE との整合のために分離型の位置符号化を併用する。結果は第 2 章に示した通り、1 トークンあたり約 70 KB——GQA 勢の 4.7〜7.4 分の 1 である。

MLA には弱点があった。テンソル並列時に潜在キャッシュが各ランクに複製されてしまう。GTA / GLA（Zadouri, Strauss, Dao, 2025, arXiv:2505.21487）はこれを正面から解く。GTA は K と V の状態を結合して GQA 品質を保ちつつキャッシュを約半分に、GLA は MLA 品質のまま分割並列に適した形へ再設計した。投機的デコード（クエリ長 > 1）では FlashMLA 比で最大 2 倍速い。

そして TransMLA（2025, arXiv:2502.07864）が示したのは、GQA は MLA の特殊ケースとして厳密に表現できる（逆は成り立たない）という代数的事実である。ゆえに既存の GQA チェックポイントを MLA へ変換できる。LLaMA-2-7B で KV の 93% を圧縮、8K 文脈で 10.6 倍高速化、必要な追加学習は 60 億トークンのみ。Ant Group の Ling-2.5-1T で実運用されている。

より過激な方向として、Keyless Attention（2026.6, arXiv:2606.21848）は K 射影そのものを廃す。キー空間へ写す代わりに、クエリを値空間へ直接ルーティングする行列を置き、推論時にはそれをクエリ行列へ融合してしまう。K は計算もされず保存もされないため、KV キャッシュは構造的に半減する——共有や量子化のような近似ではなく、片方が存在しなくなる。MHA / MQA / GQA / MLA それぞれの「keyless 版」が導出されている。ただし検証は 1.5B 級までで、7B 超での挙動と既存の FlashAttention 系カーネルとの適合は未確認である 要確認。

5.2 退避と疎化：唯一、情報を捨てる系統

Fig. 2 で n の列だけを強調したのには理由がある。他の系統が「同じ情報をより少ないビットで持つ」のに対し、この系統だけが情報を実際に捨てる。ゆえに固有の失敗モードを持つ。

H2O（2023, arXiv:2306.14048）は累積 Attention スコアの大きい「ヘビーヒッター」トークンと直近トークンのみを固定予算内で保持する。20% の保持でスループット最大 29 倍。Scissorhands（2023, arXiv:2305.17118）は「一度重要だったトークンは重要であり続ける」という重要度の persistence 仮説を立てた。

StreamingLLM（2023, arXiv:2309.17453）は別種の発見をもたらした。先頭の数トークンが softmax の質量を不釣り合いに吸収するアテンションシンク現象である。これらのシンクと直近窓だけを残せば、追加学習なしに 400 万トークンまで perplexity が安定する。ただしこれは圧縮手法ではなくストリーミング手法であり、中間の内容は完全に捨てられる。

その後の展開は「捨て方をどう賢くするか」の探索史である。SnapKV（2024, arXiv:2404.14469）は prefill 末尾の観測窓の Attention パターンが以後に必要なトークンを予測できるとした。PyramidKV / PyramidInfer（2024）は重要トークン数が層を上がるにつれ減ることを見出し、層ごとにピラミッド型の予算を配分する（12% の保持で全キャッシュ相当）。Ada-KV（2024, arXiv:2407.11550）はヘッド単位の適応的予算配分を既存手法へ後付けできる形で提供した。

転機はクエリ依存への移行である。Quest（2024, arXiv:2406.10774）は KV をページ化し、各ページのキーの最小値・最大値を保持して、現在のクエリベクトルに対して各ページの重要度を毎ステップ推定する。静的なプロファイルではなく、都度判断する。恒久的な退避を行わない点が本質的な差である。

さらに重要な理論的支柱が Retrieval Head（2024, arXiv:2404.15574）である。長文脈からの事実検索を担っているのは、少数の、モデル固有かつ安定した Attention ヘッドであることが機構的に示された。針の検索に成功するときこれらのヘッドが確実に発火し、幻覚時には発火しない。DuoAttention（2024, arXiv:2410.10819）はこれを直接設計へ翻訳し、ヘッドを「検索ヘッド（全 KV が必要）」と「ストリーミングヘッド（シンク＋直近で足りる）」に分類して二層キャッシュを構成した。

この系統に共通する二つの構造的制約

第一に、検索性能の崩壊。 恒久退避手法（H2O, StreamingLLM）は perplexity では健全に見えながら、純粋な needle-in-a-haystack 検索において一桁パーセント台の正答率まで落ちることが、複数の後続論文で繰り返し報告されている（全 Attention は約 100%）。

第二に、FlashAttention との非互換。 生の Attention 重みをスコアとして読む手法（H2O, SnapKV, TOVA, Keyformer の系譜全体）は、そもそも n×n 行列を実体化しない FlashAttention の上では動作しない。これは精度とは独立したデプロイ阻害要因である。ベンチマークを全て通過してもなお、実運用スタックに載らない。近年の研究が、Attention 重みではなく保存済み K/V のみから代理信号を作る方向へ向かっているのはこのためである。

2025 年、この問題への回答は疎性を事後に貼り付けるのをやめ、事前学習に組み込むという形で現れた。DeepSeek の NSA（Native Sparse Attention, 2025, arXiv:2502.11089）は、圧縮・選択・スライディングウィンドウの 3 分岐を並列に持ち、端から端まで学習可能なハードウェア整合的階層疎性を構成する。Moonshot AI の MoBA（2025, arXiv:2502.13189）は MoE 式のルーティングを Attention に適用し、クエリが学習されたルータを通じて KV ブロックの部分集合を選ぶ。Kimi の長文脈リクエストで実運用されている。この「事前学習に組み込む疎性」という路線は、2025 年末以降に DeepSeek の DSA を起点として広く波及し、ハイブリッドの「厳密側スロット」を占めるに至る（第 7.3 節）。

5.3 量子化：最も費用対効果の高い一手

量子化系統の到達点は明快である。K はチャネル方向（per-channel）、V はトークン方向（per-token）に量子化せよ。 この非対称性が KIVI（2024, arXiv:2402.02750）の中核的発見であり、以後ほぼ設計上のコンセンサスとなった。KIVI は追加学習なしの 2bit 量子化でピークメモリ 2.6 倍削減、バッチ 4 倍、スループット 2.35–3.47 倍を得ている。

KVQuant（2024, arXiv:2401.18079）は、K の量子化を RoPE 適用前に行うべきこと、K/V の値分布が非一様であるため非一様量子化が要ること、外れ値を疎成分として分離すべきことを示した。3bit で perplexity 劣化 0.1 未満。80GB A100 一枚で LLaMA-7B の 100 万トークン文脈を可能にする。Coupled Quantization（2024, arXiv:2405.03917）はチャネル間の相互依存を利用して1 チャネルあたり 1 ビットまで到達した。

実務的には、量子化は最初に引くべきレバーである。精度リスクがほぼなく、他のあらゆる系統と乗算的に合成でき、実装も比較的単純だからである。

5.4 層をまたぐ共有

ヘッド間で共有できるなら、層間でも共有できるはずである。CLA（2024, arXiv:2405.12981）は隣接層をグループ化し、グループ内の全層のクエリが最下層で計算された K/V を参照する。MQA の上にさらに約 2 倍。MLKV（2024, arXiv:2406.09297）は極端には全層・全ヘッドで 1 つの KV ヘッドを共有し、MQA 比 6 倍を報告した。

YOCO（2024, arXiv:2405.05254）はより大胆に構造を変える。自己デコーダがグローバル KV キャッシュを一度だけ計算し、その上に積まれた交差デコーダが以後の全層でそれを交差 Attention で再利用する。外から見れば通常のデコーダ専用 Transformer だが、キャッシュは一度しか作られない。MiniCache（2024, arXiv:2405.14366）は学習不要で、中〜深層の隣接層の KV 状態が高い類似性を持つことを利用し、大きさと方向に分解して方向のみを補間する（マージすべきでない対には保持機構を残す）。

5.5 システム側：損失なく取れる分

ここまでの系統がいずれも何らかの近似を含むのに対し、システム系統は純粋な無駄の除去であり、精度リスクをまったく負わない。ゆえに実務上は最初に採用すべきである。

2026 年の 2 件は、それぞれ別の見落としを突いている。AsymCache（Peking Univ., arXiv:2606.02964）は、既存の無損失キャッシュ系（vLLM・SGLang）が連続した接頭辞しか扱えないことに着目し、FlashAttention と PagedAttention を拡張して非連続な複数 KV セグメントを一度の走査で処理するカーネルを作った。退避方策も、「その位置のブロックを再計算するといくらかかるか」を織り込んで最適化する。専用の CUDA/CUTLASS カーネルを要し、評価は GQA モデルに限られる（MLA は未検証）要確認。

HiSparse（2026.8, arXiv:2608.07009）が突くのは、より本質的な点である——top-k 疎 Attention は 1 ステップの計算を安くするが、容量を減らさない。選択の候補である以上、全 KV は選べる場所に residency を保たねばならず、結局 HBM を占有し続ける。HiSparse は全履歴をホスト DRAM に置き、GPU 常駐分を固定サイズに抑え、ヒット判定・LRU 置換・ホストからの取得をデコードの CUDA グラフの内側に融合したカーネルで処理する。出力はビット単位で厳密（KV の置き場所を変えるだけ）で、DSA・NSA・Quest のいずれの選択器でも再学習なしに動く。ただしホスト DRAM ≫ HBM が前提であり、Grace 系の統合メモリ機ではその前提自体が崩れると著者らは明記している。

この系統には二つの学派が並存している。同居しつつ丁寧にスケジュールする（Sarathi-Serve）か、物理的に分離する（DistServe / Splitwise / Mooncake）か。両者とも 2025–2026 年時点で実運用されており、決着はついていない。

なお、投機的デコード（Leviathan ら 2022, arXiv:2211.17192／DeepMind 2023, arXiv:2302.01318 の同時独立発見に始まり、Medusa、EAGLE-1/2/3 と続く系譜）は、出力分布を厳密に保ったまま逐次ステップ数を減らす直交した高速化である。EAGLE-3（2025, arXiv:2503.01840）は最大 6.5 倍を報告する。その検証ステップ自体がツリー Attention という特殊なマスクパターンとして実装されるため、第 4 章の IO 認識カーネル基盤に依存している点は、系譜として押さえておくべきである。

5.6 入力そのものを縮める

最後に、そもそも KV キャッシュになる前の段階で文脈を縮める系統がある。Gist tokens（2023, arXiv:2304.08467）はプロンプトを少数の「要旨トークン」へ圧縮し（最大 26 倍）、LLMLingua 系列は小型 LM で低情報トークンを除去する（最大 20 倍）。ICAE（2023, arXiv:2307.06945）は LoRA ベースのエンコーダでメモリスロットへ圧縮する。

2025 年の Cartridges（arXiv:2506.06266）は概念的に新しい。KV キャッシュそのものを学習可能なパラメータとして扱い、文書に対する合成的な自己学習によりオフラインで最適化する。結果は、配布可能な軽量成果物としての KV キャッシュである。同一メモリ予算下で DuoAttention を上回る。キャッシュを「リクエスト毎の一時構造」から「事前に作って配る資産」へ移す発想であり、2025–2026 年に形成途上の系統である。

5.7 圧縮には理論的な下界がある

ここまでの 6 系統はいずれも「どこまで圧縮できるか」を経験的に押し広げてきた。では原理的な限界はどこにあるのか。2025 年、この問いに複雑性理論からの回答が出た。

Compression Barriers（Haris & Onak, Boston Univ., 2025.2, arXiv:2502.15955）は、通信計算量の Index 問題への帰着と Johnson–Lindenstrauss 型の構成により、次を証明した。

無仮定の劣線形 KV キャッシュは存在しない

Attention に基づくトークン生成アルゴリズムは、n トークンを生成するのに Θ(nd) の空間を要する（d は KV の埋め込み次元、d ≥ Ω(log n)）。すなわち仮定を置かない限り、KV キャッシュを系列長に対して劣線形にすることは原理的に不可能である。低次元領域 d = o(log n) では Ω(d·e^d) の下界も示される。

この結果の読み方には注意が要る。下界は最悪ケース・無仮定の設定に対するものであり、実手法を否定するものではない。H2O やStreamingLLM が機能するのは、まさにデータ分布に構造的な仮定を置いているからである——ヘビーヒッターが存在する、アテンションシンクが効く、といった仮定である。この論文が確定させたのは、その仮定こそが圧縮を可能にしている唯一の資源だということである。仮定を外せば圧縮の余地はない。

第 6.4 節で見る「壁 1」——固定状態の想起容量には情報理論的な上限がある——と、この結果は同じ事柄を別の側から述べている。あちらは定数状態の再帰モデルについて、こちらは Attention の KV キャッシュについて。状態を削るという行為には、アーキテクチャを問わず理論的な底がある。

06 / Second Wave第二波：定数状態への再挑戦 2020–2026

KV キャッシュを圧縮するのではなく、そもそも作らない。第一波が A 軸（FLOPs）に賭けて敗れたのに対し、第二波は C 軸（状態サイズ）を定数にすることに賭けた。今度は理論的な壁に当たった。

6.1 状態空間モデルの系譜

この系統の根は HiPPO（2020, arXiv:2008.07669）にある。「過去を覚える」ことをオンライン関数近似として定式化し、入力信号を直交多項式基底へ射影することで、閉形式の線形常微分方程式 dc/dt = A c(t) + B u(t) を得る。この A（HiPPO-LegS 行列）が、無限に長い履歴を固定サイズの係数ベクトルへ最適に圧縮する。以後の LSSL / S4 / S5 / Mamba は全て、この行列で状態遷移を初期化する。

S4（ICLR 2022, arXiv:2111.00396）は HiPPO 行列を対角＋低ランク（DPLR）に再パラメータ化し、畳み込みカーネルを O(N log N + L log L) で計算可能にした。学習時は FFT 畳み込みで並列化し、推論時は O(N) の再帰として動く。Long Range Arena で SOTA を取った。だが決定的な弱点があった。LTI（線形時不変）である——パラメータが入力内容に依存しないため、内容に基づく「選択」ができない。

S5（ICLR 2023, arXiv:2208.04933）は S4 の多数の SISO SSM を単一の MIMO SSM へ置き換え、FFT 畳み込みの代わりに並列連想スキャン（Blelloch scan, 深さ O(log L)）を用いた。これが Mamba の選択的スキャンの直接の祖先である。

Mamba（2023, arXiv:2312.00752）の中核的貢献は選択的 SSMである。Δ, B, C を現在のトークンの関数とすることで LTI 性を破り、内容に応じて情報を伝播させるか捨てるかを選べるようにした。ただし時変になった結果 FFT 畳み込みが使えなくなるため、代わりにハードウェア認識型の並列連想スキャンを融合 CUDA カーネルとして実装している（カーネル融合と選択的再計算により (B,L,D,N) の状態テンソルを HBM に実体化しない——FlashAttention と同じ発想である）。状態サイズは D_model × N（N≈16）で、系列長によらず一定。KV キャッシュが存在しない。

6.2 双対性：全ては行列ミキサーだった

Mamba-2（ICML 2024, arXiv:2405.21060）が導入した構造化状態空間双対性（SSD）は、この分野の理論的分水嶺である。状態遷移行列 A をスカラー×単位行列に制限すると、SSM の再帰は因果的線形 Attention の一形態と代数的に同一になる。両者は同じ数学的対象——半分離可能行列、あるいは「行列ミキサー」——の異なるパラメータ化にすぎない。

この視点に立つと、乱立していたアーキテクチャが一枚の表に収まる。差は、状態遷移行列をどう構造化するかだけである。

並列学習を可能にする技法にも系譜がある。RetNet が導入したチャンク再帰（チャンク内は行列積で並列、チャンク間は再帰で状態を受け渡す）は、GLA・Mamba-2・DeltaNet が共通して再利用する骨格となった。DeltaNet（NeurIPS 2024, arXiv:2406.06484）は、逐次的にしか計算できないと思われていたデルタ則（書き込む前に古い値を消去する S_t = S_{t-1}(I − β k kᵀ) + β k vᵀ）を、Householder 行列積の WY 表現によってチャンク化 GEMM へ落とすことに成功した。Gated DeltaNet（NVIDIA, ICLR 2025, arXiv:2412.06464）は Mamba-2 のスカラーゲート（大域的な高速消去）と DeltaNet のデルタ則（精密な標的上書き）を統合し、これが Qwen3-Next で実際に使われている線形 Attention 層である。

6.3 状態を「学習する」方向へ

もう一つの潮流は、状態を固定次元のベクトルや行列ではなく小さなモデルの重みとして持つ発想である。TTT layers（2024, arXiv:2407.04620）は隠れ状態を小モデルの重みとみなし、状態更新を「入力トークンに対する自己教師あり損失の勾配降下 1 ステップ」として定義する。状態更新が文字通り推論時の学習ステップである。並列化はチャンク化された「双対形式」——多数のトークンの勾配更新をまとめて閉形式の行列積で計算する——で行い、これは DeltaNet の WY トリックと同じ精神に立つ。TTT-Linear/MLP は Mamba が頭打ちになる 16K 以降も perplexity を下げ続けた。

Titans（Google, NeurIPS 2025, arXiv:2501.00663）はこれを深く、かつ動力学的にした。神経長期記憶モジュールは深い非線形 MLP であり、「驚き」指標（予測誤差が大きいほど大きく更新）にモメンタムと適応的忘却ゲートを加えて online 更新される。短期 Attention との統合パターンを 3 つ提示している——MAC（記憶を文脈として連結）、MAG（記憶出力でゲート）、MAL（記憶を層として直列化）。200 万トークン超へのスケールを主張する。

6.4 二つの、独立した壁

第二波は第一波よりはるかに成功した。しかし「Attention を置き換える」という当初の目標は達成していない。理由は、互いに独立な二つの限界が同時に効いているためである。

壁 1：情報理論的ボトルネック（状態サイズと想起容量）

Zoology（2023, arXiv:2312.04927）は 17 モデルを事前学習して比較し、Attention 非依存モデルが Pile で最大 2.1 perplexity 劣ること、そしてその差の 82% が連想想起能力で説明できることを示した。診断用合成タスク MQAR（Multi-Query Associative Recall）を導入し、これが実言語性能の差を最もよく予測することを示している。続く Based（ICML 2024, arXiv:2402.18668）は想起と記憶のトレードオフを定式化した。固定サイズ状態は無限長の文脈を圧縮せねばならず、ゆえに想起容量は状態サイズによって原理的に上から抑えられる。これはアーキテクチャを問わず成り立つ。

壁 2：計算複雑性クラスの天井

The Illusion of State in State-Space Models（ICML 2024, arXiv:2404.08819）の結論は挑発的である。再帰的な定式化を持つにもかかわらず、S4 や Mamba は回路計算量の観点で TC0——Transformer とまったく同じクラス——に収まる。いずれも NC1 完全な「困難な状態追跡」を表現できない。古典的な非線形 RNN が自明に扱う問題である。これらのアーキテクチャにおける「状態」は幻想であり、Attention より質的に強い逐次計算能力を与えてはいない。

この二つの壁は独立している。壁 2 は Householder 型遷移や負の固有値の導入で脱出できる（RWKV-7, DeltaNet 系）。だが脱出しても壁 1 は残る。状態が定数である限り、想起容量は有限である。これが、次章で見るハイブリッド化の理論的正当化そのものである。

07 / Convergence収束点：ハイブリッドという妥協 2024–2026

第 6 章の二つの壁は、純粋な定数状態モデルが成立しないことを示した。産業側の回答は理論的に美しくはないが明快である——大半の層を安価な機構にし、少数の層に厳密な Attention を残す。2024 年以降に出荷されたほぼ全てのモデルが、この一つの妥協の変奏である。

7.1 ハイブリッドの解剖 — 二つのスロット

この分野の 2024–2026 年を「誰が何を発明したか」で追うと、無関係な提案の羅列に見える。だがハイブリッドを二つのスロットとして解剖すると、一本の流れとして読める。

  • 多数派スロット（層の 75〜92%）— 安価な機構。状態が系列長に依存しないか、参照範囲が定数で抑えられている。
  • 少数派スロット（層の 8〜27%）— 厳密な機構。長距離の正確な想起を担う。

2025–2026 年に起きたのは、新しい構造の発明ではない。両スロットの部品が入れ替わり、少数派スロットの比率が下がり、そして下げた代償を埋める補償機構が現れた——それだけである。

7.2 多数派スロットの部品

最も広く採用され、かつ最もリスクが低いのは、Attention パラダイムを一切離れない解——局所（スライディングウィンドウ）と大域 Attention の交互配置である。

  • Mistral 7B（2023, arXiv:2310.06825）：窓幅 4096 の SWA。層を積むことで実効受容野が W × 層数 に届くという論法。
  • Gemma 2（arXiv:2408.00118）：局所（窓 4096）と大域（8192）を 1:1 で交互配置。
  • Gemma 3（2025, arXiv:2503.19786）：5:1 へ変更。128K 以上の文脈目標に対して KV 膨張を抑えることが明示的な理由。
  • Llama 4 iRoPE（Meta, 2025 要確認）：RoPE 付き局所 3 層＋位置符号化なし（NoPE）の大域 1 層。
  • Character.AI：窓幅を約 1024 まで縮めた局所／大域交互配置に加え、層間 KV キャッシュ共有を併用。GQA 比で約 8 倍の削減を報告。

より攻める陣営は、多数派スロットに定数状態の再帰を置いた。Jamba（AI21, arXiv:2403.19887）と Samba（Microsoft, arXiv:2406.07522）は Mamba を、Griffin / RecurrentGemma（DeepMind, arXiv:2402.19427）は RG-LRU を採る。Samba は交互配置ではなく全層で Mamba→MLP→SWA→MLP を融合する点が独特で、128K プロンプトで 3.73 倍のスループット、1M へのゼロショット外挿を報告する。Nemotron-H（NVIDIA, arXiv:2504.03624）と Granite 4.0（IBM）は Mamba-2 を、Falcon-H1（TII, arXiv:2507.22448）は同一ブロック内で Attention ヘッドと SSM ヘッドを並列実行する構成を採った。

KDA — デルタ則をチャネル毎に細粒度化する

2026 年時点で多数派スロットの最先端にあるのが、Kimi Linear（Moonshot AI, 2025.10, arXiv:2510.26692）の KDA（Kimi Delta Attention）である。第 6 章の Gated DeltaNet の直系の改良で、差は一点に集約される。

Gated DeltaNet S_t = α_t · (I − β_t k_t k_tᵀ) S_{t−1} + β_t k_t v_tᵀ … α_t はスカラー

KDA S_t = (I − β_t k_t k_tᵀ) · Diag(α_t) · S_{t−1} + β_t k_t v_tᵀ … α_t はチャネル毎ベクトル

大域的な忘却ゲートを単一スカラーからチャネル毎の対角行列へ細粒度化した。実装は対角＋低ランク（DPLR）遷移行列に対する専用のチャンク化アルゴリズムで、一般の DPLR 形式より計算を削りつつ古典的デルタ則との整合を保つ。3:1 の KDA:MLA ハイブリッドで、フル MLA 比の KV キャッシュ最大 75% 削減、100 万トークン文脈でデコード最大 6 倍を報告する。

帰属についての注記

KDA を第 6.2 節の負固有値理論（arXiv:2411.12537）の系譜に位置づけたくなるが、Kimi Linear 論文自身は固有値や状態追跡の複雑性理論に言及していない。論文が論じる安定性は、細粒度減衰が導入する除算の数値精度についてのものである。両者の接続は外部からの解釈であって、原論文の主張ではない。

並行して、Ant Group / InclusionAI の Ling / Ring 系列は Lightning Attention ＋ MLA という別系統を走らせた（"Every Attention Matters", arXiv:2510.19338／Ring・Ling 2.6, arXiv:2606.15079）。異なる線形機構から出発して、ほぼ同じ比率帯へ独立に到達している。

7.3 少数派スロットの部品も入れ替わった

第 5.2 節で見た NSA は方法論としての貢献だった。実際に出荷されたのは DSA（DeepSeek Sparse Attention）である（V3.2-Exp, 2025.9／完全版 2025.12, arXiv:2512.02556）。

機構は NSA と似て非なるものである。Lightning Indexer と呼ばれる軽量な索引器（FP8、トークンあたり約 128 次元のキーキャッシュ。MLA 本体の 512 次元に対して小さい）が先行する全トークンを安価に採点し、その上で top-2048 のトークンを個別に選択する。NSA がブロック粒度だったのに対し DSA はトークン粒度であり、また MLA を置き換えるのではなく MLA の上に載る（"Sparse MLA"）。学習は凍結した密 Attention の出力に対して索引器をウォームアップし、その後に疎学習へ切り替える二段構成。計算量は O(L²) から O(Lk) へ落ち、API 価格 50% 超の引き下げ、長文脈推論 2–3 倍、メモリ 30–40% 削減が公称値である。

設計が実装ごと借用された事例

GLM-5（Zhipu / Z.ai, 2026.2, arXiv:2602.15763）は独自の疎機構を発明せず、DSA をそのまま採用したと論文中で明言している。GLM-4.5（2025.8, arXiv:2508.06471）が素の GQA だったことを踏まえると、これは明確な設計上の断絶である。

さらに LongCat Sparse Attention（LSA）（Meituan, 2026.8, arXiv:2608.01662）は、DSA の弱点を名指しで修正する後継として位置づけられる——索引器自体の O(L²) 採点コストと、散在した HBM アクセスのハードウェア非効率である。対策は 3 つ。Streaming-Aware Indexing（散在 KV を連続・整列レイアウトへ変換）、Cross-Layer Indexing（層間蒸留で索引結果を隣接層で再利用）、Hierarchical Indexing（粗から細への段階的絞り込み）。

ここに NSA（2025.2）→ DSA（2025.9）→ LSA（2026.8） という、各段が前段のボトルネックを明示的に潰す 3 段の連鎖が成立している。第 3 章で見た第一波が「互いに無関係な提案の並列」だったのと対照的に、この系統は累積している。DeepSeek 自身は V4（2026, arXiv:2606.19348）で CSA ＋ HCA のハイブリッドへ進んだ。機構の定義は本調査では名称以上に確認できていない 要確認が、100 万トークン文脈で V4-Pro はトークンあたり推論 FLOPs が V3.2 の 27%、KV キャッシュが 10% と報告される。

本レビューの初版は「Qwen 3.8 という旗艦世代は存在しない」と記した。これは誤りである。 Qwen3.8-Max は 2026 年 8 月に公開された（プレビュー 7 月中旬、API 提供開始 8 月 3 日、オープンウェイト 8 月 12–13 日、2.4T 総／95B アクティブ、92 層、ネイティブ 262,144 トークン文脈）。Alibaba が Max 級のチェックポイントをオープン公開した初の事例でもある。

一方で「フル Attention 層が 1 層しかない」という特徴づけは、一次情報と一致しない。公開された config.json は full_attention_interval: 4 を示しており、92 層中23 層が Gated Attention——すなわち 3:1、25% である。これは Qwen3-Next（2025.9）以来 1 年間まったく変わっていない。同時公開の密モデル Qwen3.8-27B も同じ full_attention_interval: 4（64 層中 16 層）で、二つの独立した設定ファイルが同じ結論を与える。

「1 層」という理解の出所はおそらく、姉妹モデル Qwen3.8-Flash-Next の技術報告（arXiv:2608.30320）が繰り返す "one full-attention layer in every four" という表現である。これは比率を述べたものであって、絶対数ではない。なお Qwen3.8-Max 自体には専用の技術報告が存在せず 要確認、アーキテクチャの一次情報は設定ファイルと GitHub の README に限られる。

比率表を見ると、Qwen3.8-Max の 25% はむしろ中位である。最も低いのは Nemotron-H と Granite 4.0 の 8〜10% 帯。そしてフル Attention が 0% の旗艦は存在しない（MiniMax は試みて撤退した。7.6 節）。

下限はどこにあるか

「1 層まで減らせるか」という問いには、実は直接の実験的回答がある。

  • Nemotron-Flash（NVIDIA, 2025.11, arXiv:2511.18890）は 18 層・3B のモデルで、フル Attention 3 層／2 層＋SWA 1 層／1 層＋SWA 2 層を比較した。結果は明確で、フル Attention を 1 層まで減らすと長文脈の NIAH 性能が有意に劣化する。著者らは小規模 LM であっても最低 2 層は残すことを明示的に推奨している。
  • Rethinking the Role of Efficient Attention in Hybrid Architectures（Tsinghua / OpenBMB, 2026.6, arXiv:2606.15378）は機構的な説明を与える。長距離想起の能力はほぼ全面的にフル Attention 層が担っており、効率的／線形層は主として「最適化の事前分布」として機能する——すなわちフル Attention 層の内部に検索ヘッドが形成される過程を速める（窓が大きすぎると逆に遅らせる。彼らの言う "Large-Window Laziness"）。安価な層は学習動態を助けるが、想起能力の代替にはならない。
  • NLL-Guided Full-Attention Layer Selection（2026.6, arXiv:2606.27791）は配置が効くことを示した。どの層をフルのまま残すかを層ごとの NLL 劣化で選ぶと、全層の 1/4 だけをフルにしても、素朴に 1/2 をフルにした場合とほぼ同等（LongMemEval で 64.6% 対 65.0%）。つまり固定周期（Qwen の 1-in-4 のような）は層配置として最適ではない可能性がある。
  • Neural Attention Search Linear（arXiv:2602.03681）は層単位ではなくトークン単位の適応的ハイブリッドで、固定 3:1 の Gated DeltaNet ハイブリッドを検索タスクで大きく上回った（平均 45.07 対 37.30）。

比率について現時点で言えること

普遍的な最小層数を与えた研究は存在しない。だが方向は一致している——厳密 Attention の割合には下限があり、それは 1 層より上にある。安価な層は想起を肩代わりしない。そして層数より配置が効く可能性があり、適切に選べば必要な割合は半減しうる。第 6.4 節の「壁 1」（固定状態の想起容量には情報理論的上限がある）が、層の水準で再び顔を出していると読める。

7.5 深さ方向の情報流をどう補償するか

厳密 Attention の割合を下げると、系列方向の長距離結合だけでなく、層をまたぐ情報の運搬も痩せる。2026 年、二つのラボがこの問題に対して独立に、構造の異なる回答を出した。

Attention Residuals（Kimi K3）

Kimi K3（arXiv:2607.24653）の Attention Residuals は、位置ではなく深さを添字とする第二の Attention である。層 l ごとに学習されたパセウドクエリ w_l が、埋め込み層と先行する全層 1..l−1 の出力に対して softmax で注意を張る。

αi→l = softmaxi( wl · RMSNorm(hi) )
hl = Σi αi→l · vi

実装は「Block Attention Residuals」として、約 12 層ずつ 8〜9 ブロックにまとめ、ブロック内の出力を事前に集約してからブロック単位で深さ方向 Attention を張る。メモリは O(Ld) から O(Nd) へ落ちる。K3 の構成は 93 層、(3 KDA + 1 Gated-MLA) の繰り返しに末尾の MLA 1 層を加えたものである。

層間 KV 共有とは別物である

第 5.4 節の CLA・MLKV・YOCO・Layer-Condensed はいずれも KV キャッシュの共有——Attention の入力を層間で使い回してメモリを減らす技法である。Attention Residuals は Attention の出力を深さ方向に再利用して表現力を確保するものであり、目的が逆を向いている。実際 K3 の 75% の KV 削減は KDA に帰属しており、AttnRes ではない。AttnRes は逆に計算を増やす（ブロック化で緩和）。系譜としては DenseNet 的な深さ方向スキップに近い。

Gated Residual（Qwen3.8-Flash-Next）

Qwen3.8-Flash-Next の技術報告（arXiv:2608.30320, 2026.8）は別解を提示する。残差ストリームそのものを 4 本の枝へ広げる。各枝は独立に RMSNorm され、次のブロックへは「ゲート付き読み出し」——ランク d/8 のボトルネックを通したシグモイドゲートによる加重平均——が渡る。各ブロックの出力は「ゲート付き書き込み」により枝ごとのスカラー（[0,2] にスケール）で分配される。

興味深いのは、学習後に枝が自発的に役割分化することである。1 本が長距離経路を担い（平均スキップ距離 約 10.9 層）、残り 3 本は局所に留まる（約 3.4–3.9 層）。論文はこれを、先行する Hyper-Connections の「枝間混合演算子」——推論コストの支配項だった——の置き換えとして位置づけている。

同モデルはもう一つ、少数派スロット側の変更を行っている。事前学習では 4 層に 1 層のフル Attention を置き、継続事前学習の段階でそれを QSA（Qwen Sparse Attention）へ差し替える。QSA はマイクロブロック粒度の軽量索引器で top-k 約 2048 トークンを選び、圧縮率 4、索引器には部分 RoPE（128 次元中 64）、そしてキー圧縮を位置符号化の前に行う（回転位相の異なるトークンを平均しないため）。報告値は、RULER ≥512K で 90.08 → 93.00、MRCR 1M で 20.71 → 26.44 と密 Attention を上回り、1M 文脈で prefill 7.6 倍・decode 4.9 倍。

Kimi の「深さ方向の Attention」と Qwen の「ゲート付き多枝残差」は機構としては全く異なるが、同じ問題に対する同時期の独立解である——厳密 Attention を減らした深いモデルで、どう安価かつ適応的に情報を深さ方向へ運ぶか。

7.6 揺り戻し — 自社の新機構すら生き延びない

MiniMax の完全な弧：M1 → M2 → M3

MiniMax-01 / M1 は Lightning Attention の 1:7 ハイブリッドを出荷した。ところが M2（2025 年 10–11 月）は全層フル Multi-Head Attention へ回帰した。同社の報告によれば、数千億から数兆トークン規模の継続事前学習実験を SWA を含む複数の線形 Attention 変種にわたって行ったが、推論・コーディング・エージェントタスクでフル Attention の品質に安定して並ぶものはなかった。差は SFT 後の長文脈で拡大し、32K を超える文脈での検索・多段推論・文脈内学習で有意に劣った。さらに多くの線形 Attention は学習時ですら memory-bandwidth-bound であり、加えて数値精度に敏感で実運用の低精度キャッシュと衝突する。

だがこれも終点ではなかった。M3（2026.6）の MSA（arXiv:2606.13392）で疎化へ戻る——ただし線形化にではない。索引分岐が top-k ブロックを選び、主分岐は選ばれたブロックに対して厳密なブロック疎 GQA を計算する。softmax の表現力は保たれる。なお MSA は KV キャッシュ自体を小さくしない。疎化されるのはアクセスパターンだけで、節約されるのは計算と帯域である（1M で計算 28.4 倍、prefill 14.2 倍、decode 7.6 倍）。これは MSA に限った性質ではない。top-k 型の疎 Attention はすべて同じ構造を持つ——選択の候補である以上、全 KV は選べる場所に残らねばならない。第 5.5 節の HiSparse は、まさにこの残された容量問題を階層配置で引き受ける設計である。

同種の揺り戻しがもう一例ある。StepFun の Step-3（2025.7, arXiv:2507.19427）は MFA（QK 回路の低ランク分解、原論文 arXiv:2412.19255）と、Attention と FFN を別ハードウェアへ分離する AFD を導入した。しかし後継の Step 3.5 Flash（2026.2, arXiv:2602.10604）は MFA を継承せず、3:1 の SWA／フル交互配置へ回帰している。

この二例が示すのは、第 3 章で見た第一波の教訓が形を変えて生きているということである。「理論上の FLOPs 削減が実測の高速化を意味しない」——BigBird が 2020 年に直面した問題に、線形 Attention は 2025 年にも直面した。実測と品質の両方で既存手法を上回らねば残らないという規律は、機構が自社製であっても容赦なく適用されている。

7.7 変換という第三の道

ゼロから学習するのでも事後に圧縮するのでもなく、既存の Transformer を線形／SSM モデルへ蒸留する系統が 2024–2025 年に成立した。

MOHAWK（NeurIPS 2024, arXiv:2408.10189）は 3 段階の漸進的蒸留を提案する。第 1 段階で各層の「行列ミキサー」——SSD の枠組みにおいて Transformer 層と SSM 層が共に具現する暗黙の Attention 等価行列——を直接一致させ、第 2 段階でブロック単位の隠れ状態を、第 3 段階で通常の end-to-end ロジット蒸留を行う。Llamba（2025, arXiv:2502.14458）はこれを適用し、事前学習トークン予算の 0.1% 未満（8B で約 120 億トークン）で Llama-3.x を Mamba へ蒸留した。

The Mamba in the Llama（arXiv:2408.15237）はさらに直接的で、Attention 層の Q/K/V 射影の重みをそのまま流用する。LoLCATs（arXiv:2410.10254）は、線形 Attention に元の softmax の出力を MSE で層ごとに一致させた後、LoRA で残差誤差を補正する。

これらは、第一波の遺産（線形 Attention の数学）と第二波の理論（SSD 双対性）が揃って初めて可能になった。変換が成立するのは、両者が同じ行列ミキサーだからである。

7.8 主流から外れた二つの設計

  • KSA（Kwai Summary Attention）（Kuaishou, 2026.4, arXiv:2604.24432）は、選択型疎性の一族とは軸が異なる。生のトークンやブロックを選ぶのではなく、履歴を学習可能な要約トークンへ圧縮する。チャンク境界に整列したスライディングチャンクAttention を使うため、過去の各チャンクは「完全に可視（直近）」か「要約トークンで代替（遠方）」のいずれかで、部分的に両方ということが起きない。KV コストは O(N/k)。RULER-128K でフル Attention を 5.81 ポイント上回り、128K で KV メモリ 2.5 倍削減を主張する。第 5.6 節の Gist tokens 系と第 5.2 節の疎化系の交点にある「第三の道」である。
  • Hunyuan-TurboS（Tencent, 2025.5, arXiv:2505.15431）は Mamba2 を主体に据えた数少ない大規模モデルである。128 層を AMF（Attention→Mamba2→FFN）と MF（Mamba2→FFN）ブロックで構成し、内訳は Mamba2 が 57 層、Attention が 7 層、FFN が 64 層。560B 総／56B アクティブ。純粋な SSM 路線が東西いずれでも少数派に留まっているという事実そのものが、第 6.4 節の二つの壁の傍証になっている。

7.9 何が読み取れるか

  1. これは収束であって分岐ではない。 東西を問わず、調査した全てのラボが同じ構造的な賭けに到達している——厳密 Attention を層の 8〜27% に残し、残りを安価な機構で埋める。フル Attention 0% の旗艦は存在せず、検証できた範囲で 1 層のみの旗艦も存在しない。 分かれているのは (a) 多数派スロットに何を置くか、(b) 少数派スロットに何を置くか、(c) 深さ方向の情報流をどう補償するか、の三点だけである。
  2. 「厳密側」は固定点ではなかった。 フル MHA → GQA → MLA → 学習可能疎性（DSA / QSA / MSA）と、少数派スロットの部品自体が三度入れ替わった。ここが本章で最も見落とされやすい。比率だけを追うと、この入れ替わりが見えなくなる。
  3. 比率には下限があり、配置が効く。 Nemotron-Flash の直接的なアブレーションは 1 層で NIAH が崩れることを示し、最低 2 層を推奨する。一方 NLL 誘導の層選択は、賢く選べば必要な割合が半減しうることを示した。「何層か」より「どの層か」が次の問いである。
  4. 新機構が次世代を生き延びるとは限らない。 StepFun は自社の MFA を、MiniMax は自社の Lightning ハイブリッドを、次世代で捨てた。この分野の規律は、機構の出自を問わない。
  5. 東西の差は構造ではなく賭け方にある。 中国勢はネイティブに事前学習された学習可能疎性を旗艦の第一級機構として押し出しているのに対し、西側の公開情報はスライディングウィンドウ等の構造的工夫と、サービング側の KV 最適化に寄っている。第 5 章で見た「事後に貼る疎性」の限界を、中国勢は事前学習側で解こうとしている。

08 / Crisis評価の危機

2024 年以降、この分野で最も重要な進展は新しい手法ではない。既存の手法群の評価方法が、実際の劣化を系統的に見落としてきたという指摘である。

問題の構造はこうである。KV 圧縮手法の大半は、perplexity と単一事実の needle-in-a-haystack（NIAH）検索、そして LongBench の数タスクで評価されてきた。これらは圧縮が壊すものを測る設計になっていない。

8.1 何が見落とされていたか

  1. NIAH は単一事実の検索しか測らない。 RULER は意図的に難化されており、検索の変種（single-needle, multi-key, multi-query, multi-value）に加えて集約・多段追跡・QA を含む。NIAH だけで「無損失」に見える手法は、コミュニティ自身のより新しい基準に照らせば検証不足とみなされる。
  2. 論文間の比較が成立していなかった。 KV Cache Compression, But What Must We Give in Return?（EMNLP 2024 Findings, arXiv:2407.01527）は 10 手法以上を単一環境で 7 種のタスクカテゴリにわたり初めて統一比較した。その最大の発見は経験的というより手続き的である——それ以前の論文の手法比較は、モデルもデータセットも予算もシステム構成も揃っておらず、論文をまたいだ「どれが最良か」という主張は検証不能だった。
  3. 単一リクエスト評価そのものが誤導的である。 SCBench（Microsoft, ICLR 2025, arXiv:2412.10319）の指摘。実運用（vLLM, SGLang, および主要プロバイダ）では KV キャッシュが複数リクエスト間で再利用される。ゆえに KV キャッシュのライフサイクル全体——生成・圧縮・検索・ロード——を通じて評価しなければならない。単発評価で効率的に見える手法が、キャッシュ再利用の動態下ではまったく異なる挙動を示しうる。
  4. 劣化はタスク依存であり、崩れる能力は一様でない。 Semantic Integrity Matters（HKUST, ICML 2026, arXiv:2502.01941）は KVFundaBench により、KV 圧縮下で能力ごとに劣化の仕方が違うことを示した。この報告で特徴的なのは、検索系タスクは比較的頑健である一方、高密度推論（Chain-of-Thought の連鎖）が著しく壊れるという所見である——圧縮が思考の連結そのものを断つためだと説明される。これは第 5.2 節で見た「恒久退避は検索を壊す」という所見と方向が食い違って見える。手法・予算・タスク設計が異なるため直接の矛盾とは言えないが、どの能力が先に壊れるかは設定に依存し、単一の順位付けは存在しないと読むのが妥当である。同論文はあわせて、少数事例や意味単位を不可分ブロックとして扱う ShotKV を提案し、長文生成で 9–18% の精度改善を報告している。
  5. 複数指示下で、特定の指示だけが選択的に無視される。 The Pitfalls of KV Cache Compression（UCLA, arXiv:2510.00231, ACL 2026）は最も鋭い批判である。StreamingLLM, SnapKV, TOVA, H2O, K-Norm を、単一タスクの QA や要約ではなく複数指示プロンプト（IFEval）で評価した。結果：スループット向上は本物である。しかし複数指示が同時に与えられると、ある指示だけが他より急速に劣化し、完全に無視される点まで到達する。標準的な単一指示の長文脈ベンチマークでは原理的に不可視な失敗モードである。さらにシステムプロンプト漏洩のケーススタディにおいて、圧縮が情報漏洩の挙動を測定可能なほど変えることを示した。セキュリティに関わる副作用であり、この分野の評価プロトコルにこれまでほぼ存在しなかった観点である。

機構的な説明は既にあった

第 5 章で触れた Retrieval Head（arXiv:2404.15574）は、これらの失敗の機構的な説明そのものである。長文脈の事実性を担うのは少数の特定ヘッドであり、それは本質的かつ安定している。H2O や StreamingLLM のような一様・無原則な退避は、検索ヘッドを特別扱いする機構を持たない。ゆえに壊れる。DuoAttention はこの知見を直接設計に翻訳することで問題を回避した。評価の危機と機構的解釈可能性が、同じ問題の二つの側面として接続している。

8.2 実務への含意

文献全体から導かれる実務的な順序は、意外なほど明確である。

  1. まずシステム系統を採る。 PagedAttention、接頭辞キャッシュ、連続バッチング、必要に応じて分離アーキテクチャ。これらは無駄の除去であり、精度リスクをまったく負わない。多ターン／エージェント／RAG ワークロードでは、損失を伴うリクエスト毎の圧縮より実効スループットへの寄与が大きい可能性が高い。
  2. 次に量子化。 K はチャネル方向（可能なら RoPE 適用前）、V はトークン方向に 2〜4 ビット。KIVI / KVQuant の知見に従えば精度上ほぼ無料である。
  3. アーキテクチャは一度きりの決断。 新規学習なら最低 GQA、可能なら MLA（または GTA/GLA）。既存 GQA チェックポイントなら TransMLA / Palu による事後変換という経路がある。
  4. 退避・疎化は最後に、かつ検証付きで。 perplexity や NIAH ではなく、RULER・SCBench 型の複数リクエスト評価・圧縮下の IFEval で検証すること。ここだけが情報を捨てる操作である。

09 / Open未解決問題

  1. 状態サイズと想起容量のトレードオフを回避する方法はあるか。 Based が定式化したこの限界は情報理論的であり、アーキテクチャの工夫で消せるものではない。ハイブリッドは回避ではなく棲み分けである。定数状態のまま想起を保つ方法が原理的に存在するのか、それとも本質的に不可能なのかは、まだ決着していない。
  2. ハイブリッド比率を原理的に決められるか。 8%（Nemotron-H）から 25%（Qwen3-Next）まで、実運用の比率は 3 倍以上ばらついている。どのタスク分布に対してどの比率が最適かを事前に予測する理論はない。現状は経験的な探索である。
  3. 線形 Attention の memory-bandwidth-bound 問題。 MiniMax-M2 の報告が示すように、線形 Attention は学習時ですら帯域律速でありうる。極端な I/O 工学（Lightning Attention, FlashLinearAttention）なしには理論的節約が実現しない。これは第一波の「efficiency length」問題の再来であり、根本的な解決を見ていない。
  4. FlashAttention 互換な重要度信号。 生の Attention 重みに依存する退避手法は、実体化しないカーネルの上で動かない。保存済み K/V のみから十分な代理信号を作れるのか、それとも重要度判断には本質的にスコア行列が要るのかは未解決である。
  5. 評価の再構築。 単一リクエスト・単一指示・単一事実検索という 3 つの単純化が、いずれも実運用と乖離していることが判明した。ではセキュリティ副作用（システムプロンプト漏洩）まで含めた、実運用を代表する標準評価はどう設計すべきか。SCBench と Pitfalls 論文は問題を提起したが、標準化された後継はまだない。
  6. ハードウェアの非対称進化への追随。 FlashAttention-4 が示したように、Tensor Core だけが速くなり共有メモリ帯域と特殊関数ユニットが追随しないとき、IO 最適性の定義そのものが書き換わる。アルゴリズムとハードウェアの共設計が、世代ごとにやり直しを要求する構造になっている。
  7. ネイティブ疎性はどこまで登れるか。 DSA の索引器が抱えていた O(L²) 採点コストは LSA が潰した。しかし学習可能な索引という機構そのものに、第 6.4 節の「壁 1」がどう効いてくるのかは未解明である。top-k の k を固定する限り、それは形を変えた定数状態ではないのか。第 5.7 節の Θ(nd) 下界は「無仮定なら劣線形は不可能」と述べるのみで、実データの分布がどれだけの圧縮余地を与えるのかは定量化されていない。この分野が経験的に押し広げてきた圧縮率が、理論的な余地のどのあたりに位置するのかは分かっていない。
  8. どの能力が先に壊れるかの順序は決まるのか。 検索が先に壊れるという報告と、高密度推論が先に壊れるという報告が併存している（第 8.1 節）。手法・予算・タスクのどの軸がこの順序を決めるのかが分かれば、圧縮の設計指針になる。
  9. 比率 3:1 の理論的導出。 東西の独立したラボが経験的に同じ帯域へ収束していることは、説明されるべき現象であって、説明ではない。
  10. KV キャッシュの「資産化」。 Cartridges 系統が示唆するように、KV キャッシュを事前計算・配布可能な成果物として扱う方向は、圧縮とは異なる軸である。この方向がどこまで一般化できるかは、2026 年時点で形成途上である。
