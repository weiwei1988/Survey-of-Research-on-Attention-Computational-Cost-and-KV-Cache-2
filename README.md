# Survey-of-Research-on-Attention-Computational-Cost-and-KV-Cache-2

2018〜2026年のAttentionの二次計算量とKVキャッシュ問題を、195件の論文・公式資料と214本の系譜線から辿るローカル研究マップです。HTMLとJavaScriptだけで動作し、外部ライブラリの読み込みもビルドも不要です。同じ調査から書き起こした文献レビュー（全10章）を同梱し、Appendixに内容を記載しています。

公開サイト: <https://weiwei1988.github.io/Survey-of-Research-on-Attention-Computational-Cost-and-KV-Cache-2/>

- MAP: [map.html](https://weiwei1988.github.io/Survey-of-Research-on-Attention-Computational-Cost-and-KV-Cache-2/map.html)
- 文献レビュー: [review.html](https://weiwei1988.github.io/Survey-of-Research-on-Attention-Computational-Cost-and-KV-Cache-2/review.html)

GitHubのファイル表示ではHTMLが描画されずソースが出るため、上のリンクから開いてください。

## 使い方

リポジトリを取得し、`map.html` をブラウザで開いてください。MAPの表示にネット接続は不要です。Webフォントのみ外部から取得しますが、取得できない場合は代替フォントで表示されます。一次資料のリンクを開く際はネット接続が必要です。

```bash
git clone https://github.com/weiwei1988/Survey-of-Research-on-Attention-Computational-Cost-and-KV-Cache-2.git
cd Survey-of-Research-on-Attention-Computational-Cost-and-KV-Cache-2
open map.html
open review.html
```

- 横軸は発表年（2018〜2026、年内の月まで反映）、縦の11レーンは研究系統、色は近似・定数状態・厳密・KV圧縮・システム・実運用モデル・理論評価の7つの立場を表します。
- ノードを選ぶと、右のパネルに論文名・著者・出典・要約・中核機構・限界と含意・直接の源流と後継を表示します。同時に、その論文の祖先と子孫をすべてハイライトします。
- 源流・後継はボタンになっており、押すとその論文へ移動します。系譜を続けて辿れます。
- 全195件に日本語122〜210字（平均172字）の要約があります。
- 表示名・IDでの検索、7つの立場での絞り込み、選択した論文に連なるノードだけを残す系譜モードに対応します。選択があるときは系譜の表示が検索より優先されます。
- ドラッグで移動、ホイール・ダブルクリック・`+` `-` キーで拡大縮小、`0` キーまたは⊡ボタンで全体表示に戻ります。
- タッチ操作ではピンチで拡大縮小できます。軸ラベルは拡大率によらず同じ大きさで表示し、狭い画面では重なるものを間引きます。レーンの色帯は残るため構造は見えたままです。

## 収録範囲と注意点

調査基準日は2026年9月4日で、それ以降の文献は入っていません。2025〜2026年の各社アーキテクチャは特に更新が速く、複数のラボが1年内に2〜4回の版更新を行っています。版番号と帰属は基準日時点のものとして読んでください。

論文に加えてモデルカード、公式技術記事、実装公開も含み、すべてが査読済み論文ではありません。原題を特定できたものは194件、arXivの一次ソースURLが確定するものは185件です。残る10件はブログ・GitHub・モデルカード・組織発表が出典で、URLを推測せず空欄にしています。原題を確認できなかった1件（`softmaxvslinear`, arXiv:2310.11685）も空欄のままです。

要約はアブストラクトと公式資料に基づく編集要約で、全文精読や独立再現を意味しません。性能値や理論上の主張は原資料の条件と合わせて確認してください。系譜線は改良・発展・評価の整理であり、すべてを直接の引用関係とみなすものではありません。

構造的な主張（4軸の区別、prefillとdecodeの非対称性、FlashAttentionがFLOPsを下げていないこと、SSD双対性、状態サイズと想起容量のトレードオフ、評価の危機）は複数の独立した一次情報で裏付けています。一方、最新世代のモデルの帰属と個別の数値は精度が落ちます。一次情報に到達できなかった項目には本文中に `要確認` を付し（10箇所）、文献レビューの第10章にすべて列挙しています。Qwen3.8-Max（2026年8月）に専用の技術報告がないこと、DeepSeek V4のCSA/HCAの機構定義が未確認であることなどが該当します。

確認できないものを推測で埋めない方針で作成しています。初版の誤り（Qwen 3.8の実在、および2026年の中国勢を「分岐」として立てた構成）は、削除せず訂正として本文に明記しています。

なお、この調査は同一テーマの独立調査（51件）と arXiv ID で突き合わせており、43件が重複、新規増分は8件でした。重複率の高さは、両調査が主要文献の骨格について独立に同じ結論へ達したことを意味します。

## Appendix: 文献レビュー

`review.html` は、MAPに載せた195件を通して読むための本文です。2018年以降、Attentionの計算量を改善する提案は200本を超えましたが、そのうちフロンティアの大規模言語モデルで既定のAttention機構の置き換えとして採用されたものは1つもありません。「Attentionが重い」という一文が、実際にはFLOPs（漸近計算量を下げたか）・実体化（n×nをメモリに置かずに済むか）・状態サイズ（KVや再帰状態を劣線形にしたか）・厳密性（出力が数学的に厳密か）という4つの別々の主張を含んでいたことを出発点に、全手法をこの4軸で分類して整理しています。

| 章 | 内容 |
| --- | --- |
| 1 | すれ違いの構造 — 4軸の導入 |
| 2 | 問題の定式化 — prefillとdecodeの非対称性、KVサイズ式、デコードのルーフライン |
| 3 | 第一波：近似の時代（2018〜2022） — 疎化・線形・再帰の4系統と、全滅した6つの理由 |
| 4 | 転回：FlashAttention — FLOPsを下げずにIO下界を達成し、近似の前提を消した |
| 5 | 戦場の移動：KVキャッシュ — サイズ式の各項に対応する6系統と、圧縮の理論的下界 |
| 6 | 第二波：定数状態への再挑戦 — SSM・線形RNN、SSD双対性、2つの独立した壁 |
| 7 | 収束点：ハイブリッドという妥協（2024〜2026） — 安価な多数派スロットと厳密な少数派スロット |
| 8 | 評価の危機 — NIAHでは見えない劣化、SCBench、Retrieval Head |
| 9 | 未解決問題 |
| 10 | 出典と検証状況 — `要確認` 項目の全列挙 |

第7章がこの調査の到達点にあたります。ハイブリッド構成を2つのスロットに分けて見ると、多数派スロットがスライディングウィンドウからMamba、Gated DeltaNet、KDAへ移る一方で、少数派スロットもフルMHAからGQA、MLA、学習可能な疎Attention（DSA/QSA/MSA）へ三度入れ替わっていることが分かります。比率だけを追うとこの動きは見えません。
